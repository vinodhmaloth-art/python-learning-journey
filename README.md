# Python Learning Journey

My daily Python practice repository — small programs from my structured mentoring program, where I learn one topic at a time and solve a practice problem after each topic.

## My journey so far

| Day | Topic | Practice problem |
| --- | ----- | ---------------- |
| Day 1 | Variables & printing | Store name, age and favourite number, print them in one sentence |
| Day 2 | Numbers & input | Take two numbers, print sum, difference, product and division |
| Day 3 | Conditions (if / else) | Marks 40 or more = Pass, else Fail |
| Day 4 | Loops (for / while) | Print 1 to 20 with Even or Odd next to each number |
| Day 5 | Strings | Name in UPPERCASE, letter count, first and last letters |
| Day 6 | Lists | Marks list — total, average and highest mark |
| Day 7 | Counting patterns | Count Pass and Fail from a marks list |

## Files

- day01_basics.py — variables, input and printing
- day02_conditionals.py — if / else
- day03_loops.py — for and while loops
- day04_lists.py — lists
- day05_counting.py — counting and simple problem-solving
- day06_strings.py — strings
- day07_counting.py — the Friday counting practice (Pass: 3, Fail: 2)
